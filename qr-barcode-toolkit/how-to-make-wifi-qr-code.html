How to make a Wi-Fi QR code

A Wi-Fi QR code lets guests join your network by pointing their phone camera at it. No spelling out a long password. Here is how to make one with QR & Barcode Toolkit, for free.

Steps

  1. Open the app and tap Generate.
  2. Choose WiFi from the list of code types.
  3. Type your Network name (SSID) exactly as it appears on your phone, including capital letters.
  4. Enter the Password.
  5. Pick the Encryption your router uses. Most home routers use WPA or WPA2. Choose none only for an open network.
  6. If your network is hidden, tick Hidden network.
  7. Tap Save PNG to keep the image, or Share to send it.

How guests use it

Most recent Android phones and iPhones can read QR codes with the normal camera app and offer to join the network. Print the code and keep it near the router, in a guest room, or at a shop counter.

Good to know

  • Anyone who can see the code can join. Don't post it publicly if the network is private.
  • If you change the Wi-Fi password, make a new code, because the old one holds the old password.
  • Test it once with your own phone before you print it.
  • The code is made on your phone. The app doesn't need an account.

Tip: you can also scan an existing Wi-Fi code with the app. It shows the network name and lets you copy the password.
