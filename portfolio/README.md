# Gaurav Kumar - DevOps Portfolio

Single-file static site (`index.html`). No build step.

## Deploy on GitHub Pages
1. Copy `index.html` into the root of the `gauravkumarit8.github.io` repo (replace the old one).
2. Commit and push to the default branch.
3. The site updates at https://gauravkumarit8.github.io (and your custom domain if configured).

## Things to edit
- LinkedIn button: search for `href="#">LinkedIn` and put in your URL.
- Project links: update the GitHub repository link in the Projects section.
- Email and copy: search for `gaurav.kumarit8@gmail.com`.

## Lab project
The `devops-lab/` folder is a separate project (Terraform + Prometheus + Alertmanager + Grafana).
Create a GitHub repo named `devops-lab`, push that folder's contents, and the portfolio link
https://github.com/gauravkumarit8/devops-lab will work. Run it once before listing it on your resume.
